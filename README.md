# Java Day 34 - Largest Element at Even Indexes

This Java program finds the largest element stored at an even index in an array.

## Example

Array:
`[25, 80, 45, 20, 60, 90]`

Even indexes: `0, 2, 4`

Output:
```text
Largest element at even indexes = 60
```

## Concepts Used

- Arrays
- `for` loop
- `if` statement
- Array indexing
- Comparison operator `>`
- Increment by 2 (`i += 2`)

## How It Works

The program starts with the element at index zero as the largest value. It checks the remaining even indexes and updates the largest value whenever a bigger element is found.
